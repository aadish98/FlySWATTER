# user_scripts/

Put your own scripts here (subfolders are fine, e.g. `user_scripts/<your_name>/<project>/`).

- Everything in this folder except this README is ignored by git, so `git pull` and app updates never touch it.
- Import FlySWATTER modules from here if you need them, but don't edit the app code itself.
- Outputs from the app are in `../Data/`.
